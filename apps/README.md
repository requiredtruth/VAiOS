# Recovered VAiOS apps

These are exact owner-authored `.vaios` artifacts recovered alongside the original desktop. A `.vaios` package is JSON, not a ZIP archive. Install packages with **App Manager** or **Mass Import .vaios**.

Published packages are limited to artifacts whose source and redistribution status can be described honestly:

- `html-to-vaios.vaios`
- `url-to-vaios.vaios`
- `neon-kart-16.vaios`
- `philippines-skyline-webcam-wall.vaios`

The webcam wall embeds public pages and contains no stream URLs, access tokens, or media. Those pages can refuse framing or change independently.

Recovered packages tied to third-party commercial games are not included because their redistribution rights were not established.
